# Violite Control — панель управления

Панель работает с реальным Control API и SQLite. Вход — пароль и TOTP;
прямое открытие dashboard.html не обходит авторизацию. Рабочая страница
загружает assets/live.js.

## Запуск

Запускайте control-server/server.js по инструкции в ../control-server/README.md.
Обычный статический сервер на 8765 не предоставляет API и больше не подходит
для рабочего входа. Локальная панель Control по умолчанию доступна на 8792.

Рабочий адрес панели (с любого устройства, HTTPS):

https://panel.193-39-143-31.sslip.io

Вход — логин `owner`, пароль и код TOTP из Authenticator. Данные первого входа —
в приватном файле .local/control-production/FIRST-LOGIN.txt в корне проекта
(пароль — в менеджер паролей, TOTP — в Authenticator, файл потом удалить).
Не помещать эти данные в Git.

Запасной вход через SSH-туннель продолжает работать:

```powershell
ssh -N -L 8090:127.0.0.1:8090 -i "$env:USERPROFILE\.ssh\skin_relay" root@193.39.143.31
```

затем http://127.0.0.1:8090.

## Реализовано

- Обзор: кто в игре, устройства, аккаунты, опубликованные версии, последние события.
- Сессии: группировка по HWID, внутри — аккаунты Roblox (имя и аватар), версия с названием.
- Пользователи: HWID → аккаунты; клик по строке открывает карточку управления
  (завершить сессии, бан/разбан HWID, бан всех HWID аккаунта).
- Блокировки только по HWID. Бан по Roblox User ID блокирует все HWID,
  на которых этот аккаунт запускал скрипт. Старые баны аккаунта/ключа показываются,
  пока их не снимут.
- Фильтры и постраничный вывод во всех таблицах (размер страницы запоминается).
- Релизы, цены, журнал, обслуживание. Светлая и тёмная тема (по системе или вручную).

Аватары и имена отдаёт `GET /api/roblox` (сервер Control, кэш 6 ч). Со старым
сервером (без `api:2` в `/api/state`) панель работает без аватаров и без бана HWID.

## Обновление

Сервер больше не берёт панель из GitHub: UI выкладывается вместе с backend командой
`control-server\deploy\deploy.ps1` (см. ../control-server/README.md, «Обновление и откат»).
Файлы рабочей панели отдаются только после входа.

Контракт API, развёртывание и резервное копирование описаны в
[control-server/README.md](../control-server/README.md).
